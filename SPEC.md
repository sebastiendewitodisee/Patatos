# Team Patates Patatos — Page Infos

Objectif: une page unique (statique) qui centralise toutes les infos du projet patates.
Public: l’équipe (on est 5).
Ton: fun mais clair.

Contenu de la page:
1) Header: "Team Patates Patatos" + petit sous-titre.
2) Bloc "Statut actuel": étape en cours + prochaine action.
3) Checklist "À faire maintenant" (ex: trouver un endroit pour faire germer, organiser l'espace, etc.)
4) Timeline complète "Achat → Germination → Préparation sol → Plantation → Entretien → Récolte → Stockage/partage"
   Pour chaque étape: objectif + checklist.
5) Bloc "Germination (mode d’emploi)": lumière, température, ventilation, signes d’alerte.
6) Zone "Notes" en bas.

Tech souhaitée:
- Site très simple, rapide.
- Vite + React + Tailwind.
- Responsive mobile.
- Tout le contenu dans un fichier `src/data/project.js` (ou .json) pour pouvoir modifier facilement.

Pages:
- Une seule page (Home).
